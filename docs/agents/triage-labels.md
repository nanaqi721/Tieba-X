# Triage Labels

Use the following one-to-one GitHub label vocabulary:

- `needs-triage`: the request has not been classified or verified.
- `needs-info`: implementation is blocked on missing stakeholder information.
- `ready-for-agent`: the issue contains enough detail for an agent to implement.
- `ready-for-human`: the next action requires a human decision or external operation.
- `wontfix`: the request was deliberately rejected or closed without implementation.

Preserve an existing equivalent repository label instead of creating a duplicate if GitHub already has one.
