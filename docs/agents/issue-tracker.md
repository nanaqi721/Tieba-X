# Issue Tracker

Use GitHub Issues in `nanaqi721/Tieba-X` for specifications and implementation tickets:

- Repository: https://github.com/nanaqi721/Tieba-X
- Issues: https://github.com/nanaqi721/Tieba-X/issues

Specifications produced by `to-spec` are published as issues and labeled `ready-for-agent` once they contain enough implementation and testing detail for another agent to begin without another requirements interview.
