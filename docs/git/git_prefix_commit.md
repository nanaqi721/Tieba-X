补充前缀

- revert：回滚某个提交
- merge：合并分支
- init：项目初始化
- release：版本发布

标准格式

<前缀>(<范围>): <描述>

# 例：
feat(user): 增加用户注册接口
fix(auth): 修复 token 过期后仍可访问的 bug
docs(readme): 补充安装说明
chore(deps): 升级 lombok 到 1.18.42

要点：
- 范围（scope）是可选的，小写，指影响模块（如 auth、user）
- 描述用祈使句、小写开头，简洁描述"做了什么"
- 破坏性变更加 !，如 feat!: 变更 API 结构，或正文里写 BREAKING CHANGE:
- 这也是我们刚才那几件事的合适前缀：build(deps): 删除无效的 spring-boot-maven-plugin、chore: 添加 .gitignore
